## 数据损坏风险

本分支修复多个能成功导出却丢失数据的路径，并对不支持情况明确失败。但是不能保证所有格式变体与任意编辑场景正确：Group/Signed 权重、重算 tangent、编辑后仍沿用 Explicit 半径、未理解的 bbox 关联和未验证的游戏行为仍有风险。测试通过的合成子集不代表全格式或游戏资产通过。

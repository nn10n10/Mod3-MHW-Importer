## 当前数据安全边界

未修改、完整导入的 unresolved 模型写回整个原始文件，五个真实 source/A/B 完整 bytes 一致；相关编辑、丢失/篡改 baseline 或无法验证的设置在写入前失败。这防止本路径把 Blender 的 normal 差异写回源文件。它不证明任意重建、格式变体或游戏外观正确。

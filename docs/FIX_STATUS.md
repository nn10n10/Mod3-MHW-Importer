## 仍需完成

1. 在本机或 CI 使用真实 Blender 5.2 LTS，运行全部 Blender 测试并保存版本。
2. 为五个用户模型确定 bounding-box 引用语义；需要来源可靠的原始模型、格式说明或 upstream 确认。不能按猜测重分配 bbox。
3. 成功完成真实游戏模型 source→A→B，比较全部语义并确认 source/A 差异；再做游戏内加载/外观检查。
4. 实际验证 Windows TEX/DDS 转换与中文路径；本次没有执行 EXE。
5. 解决 license 和二进制许可问题；确认 upstream 接受兼容版本范围与主动拒绝有损导出的策略。

## 数据损坏风险

本分支修复多个能成功导出却丢失数据的路径，并对不支持情况明确失败。但是不能保证所有格式变体与任意编辑场景正确：Group/Signed 权重、重算 tangent、编辑后仍沿用 Explicit 半径、未理解的 bbox 关联和未验证的游戏行为仍有风险。测试通过的合成子集不代表全格式或游戏资产通过。
